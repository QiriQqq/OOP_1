# OOP_3 — лабораторная работа №3

Папка предназначена для отдельной локальной работы над ЛР3 и может быть размещена в отдельной ветке репозитория.

## Структура

- `src/` — приложение и предметная модель, перенесённые из предыдущей лабораторной. Проект называется `OOP_3.App.csproj` и содержит демонстрационный `Program.cs` с `Main()`.
- `tests/` — тесты xUnit, ручные тестовые дублёры и проверки NSubstitute. Проект называется `OOP_3.Tests.csproj`.
- `TESTS.md` — соответствие правил предметной области конкретным тестам.
- `MUTATIONS.md` и `RunMutations.ps1` — описание и запуск пяти мутаций.

Имена двух `.csproj` намеренно различаются. Тестовый проект ссылается на приложение через `../src/OOP_3.App.csproj`. Благодаря этому исходники приложения не компилируются повторно внутри тестового проекта, а `Main()` остаётся только в приложении.

## Запуск

Команды выполняются из папки `OOP_3`, в которой находятся `src`, `tests` и `RunMutations.ps1`.

Восстановить зависимости и запустить тесты:

```powershell
dotnet restore tests/OOP_3.Tests.csproj
dotnet test tests/OOP_3.Tests.csproj
```

Запустить демонстрационное приложение отдельно:

```powershell
dotnet run --project src/OOP_3.App.csproj
```

Запустить мутационный сценарий в PowerShell:

```powershell
.\RunMutations.ps1
```

Задание 2 не включено по просьбе пользователя. Для задания 4 использована адаптация к варианту сотрудников, поскольку отдельный учебный проект преподавателя отсутствует.
